# Portfolio news bot

Бот, который отслеживает новости РБК и Smart-lab по списку тикеров
и присылает совпадения в Telegram. Настроен на автозапуск каждые
10 минут через GitHub Actions — см. `.github/workflows/news.yml`.

## Настройка (один раз)

1. Создайте новый **публичный** репозиторий на GitHub и загрузите
   в него все файлы из этой папки (сохранив структуру, включая
   папку `.github/workflows/`).
2. В репозитории откройте **Settings → Secrets and variables → Actions
   → New repository secret** и добавьте два секрета:
   - `TELEGRAM_TOKEN` — токен вашего бота от BotFather
   - `TELEGRAM_CHAT_ID` — ваш chat_id (112195285)
3. Откройте вкладку **Actions** — workflow "Portfolio news bot" появится
   автоматически. Можно сразу нажать **Run workflow**, чтобы проверить
   вручную, не дожидаясь расписания.
4. Дальше бот будет запускаться сам каждые 10 минут.

## Изменение списка тикеров

Список акций и ключевых слов для поиска находится в файле
`portfolio_news_bot.py`, в словаре `PORTFOLIO`. Чтобы изменить состав
портфеля — отредактируйте этот словарь и загрузите обновлённый файл
в репозиторий (закоммитьте изменения).
